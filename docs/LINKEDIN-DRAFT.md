# LinkedIn launch post — DRAFT (copy-paste ready)

> I built the thing I wish existed when I was learning to code.
>
> AI agents are incredible — but somewhere along the way I realized I was shipping code I couldn't explain. So I built Teachify: Teach Mode for any LLM.
>
> Give it the same prompt you'd give an agent — "implement JWT auth" — and instead of doing it, it breaks the task into verifiable steps and guides you through them one at a time. You type the code. It verifies each step, gives escalating hints (never the answer), and quizzes you at the end.
>
> The AI guides. You type. You learn.
>
> Two commands to try it:
> `pip install teachify`
> `teachify install` ← connects it to Claude Code, Cursor, Copilot CLI, Codex, VS Code automatically
>
> Then: `/teach <anything you want to learn>`
>
> Open source (MIT): https://github.com/iamamansid/teachify
>
> Honest feedback welcome — what's the first thing you'd want it to teach you?
