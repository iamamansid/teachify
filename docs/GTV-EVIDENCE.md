# GTV Evidence Tracker — Teachify

> Read this before using Teachify as Global Talent Visa evidence. This file is a
> **tracker**, not a guarantee. Tech Nation judges the application **holistically**:
> you need **1 mandatory criterion + 2 optional criteria + 3 recommendation letters**,
> up to 10 evidence documents (max 3 A4 pages each). Stars alone do not endorse anyone.

## What Tech Nation looks for (Digital Technology route, Tech Nation endorsement)

- **Mandatory:** recognised as a leading talent (Talent) or potential leader (Promise) in digital technology.
- **Optional (pick 2 of 4):** Innovation / Recognition & advancement of the field /
  Significant contribution / Academic & research.
- **Letters:** 3 letters from senior people in tech, from different organisations where possible,
  speaking to *specific* contributions — not generic praise.
- **Rules that catch people out:** evidence must generally be from the last 5 years;
  evidence that looks created solely for the application is penalised; check the current
  Tech Nation guide for the exact AI-use rules for the application itself before drafting.

Teachify can credibly support **Optional — Innovation** (a new Teach Mode for agents)
and **Optional — Recognition / advancement of the field** (open-source impact +
mentoring juniors at scale). It does **not** by itself satisfy the Mandatory criterion
or replace letters. Plan the full portfolio, not just this repo.

## Qualitative evidence (matters as much as stars)

Collect, with permission + date + link:

- [ ] **User testimonials:** "I finally understood X because of Teachify" — quote + name + link.
- [ ] **External contributors:** PRs from people you don't know (especially new-task PRs).
- [ ] **Adoption:** teams / classrooms / bootcamps using it; download / install counts.
- [ ] **Talks / demos:** meetup / conference talks, workshops, live demos (in-person counts more).
- [ ] **Media:** blog posts, YouTube walkthroughs, newsletter mentions by third parties.
- [ ] **Citations:** anyone referencing Teachify in their own work / teaching.
- [ ] **Letters:** ask 3 senior referees *early* — they need time, and their letters must map to specific criteria.

## What NOT to count

- Stars from friends / pods with no usage. Assessors look for real adoption.
- Your own forks / PRs.
- Vanity metrics with no link to your contribution (e.g. "the repo was viewed N times").

## Checklist before submitting

- [ ] 10 evidence docs drafted, each mapped to exactly one criterion.
- [ ] Each doc is ≤3 A4 pages, dated, and externally verifiable (links / screenshots).
- [ ] 3 letters secured, each specific, each from a different context.
- [ ] Personal statement explains *your* contribution (not just "the repo exists") and your future contribution to the UK tech sector.
- [ ] No AI-generated application text if the current Tech Nation rules prohibit it — verify the current guide.
